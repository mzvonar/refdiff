RefDiff — item navigation spec No screens here on purpose: every state lives in the measured comps so the two drawings can't drift. Reach the states by clicking the data-vc-step triggers listed below.
Where each state lives
  • RefDiff Comparison Tool — frame “RefDiff comparison tool”. Switcher pill in the header (resting). nav-list = click the item name → item-list popover. Hover the next arrow → preview card (hover-only, not measured).
  • RefDiff Mobile — frame “RefDiff mobile toolbar”. Resting: 5/11 counter beside the brand square + 2 px progress hairline under the header. nav-open = tap brand/counter → header in switcher mode. nav-sheet = tap the list icon in switcher mode → bottom sheet.
  • RefDiff Library Groups — frame “Library — grouped”. Button group is open by default; visit-cell = click the cell “Primary · md · Hover” → returned-from-comparator state (group + item marked, row scrolled into view).
  • RefDiff Library Groups Mobile — frame “Library — grouped (mobile)”. Same visit-cell trigger.
A · Just-visited trail (Library)

State lastVisited = { groupId, itemId, timestamp }, persisted per project; written whenever the comparator opens an item (including prev/next and list switches). Only overwritten by another open; survives filters, reloads, theme.

On Library mount with a trail: expand the group (other groups keep their state); scroll the item row into view (centred, no animation on first paint); group row → 3 px accent bar on the left edge, bg2 background, tinted pill “Just visited” (vis bg, acc text, my_location icon) right of the name — mobile group card also gets a 1 px acc outline; item row → 3 px accent bar, vis background, filled acc pill “Just visited · {relative age}” after the name, CTA “Compare” → “Reopen” (mobile: chevron → replay icon in acc).

“Jump to just visited” appears only while the marked row is out of view. Decision: desktop draws it as a link in the sticky topbar (left of the theme toggle); mobile draws it as an overlay pinned under the sticky topbar (zero-height sticky wrapper, so nothing in the flow shifts as it appears/disappears). Both are reachable in the comps by triggering visit-cell and scrolling away. If the item no longer exists, mark the group only and hide Jump.

Token note: --vis is the accent at 14 % (dark) / 12 % (light) alpha — a tint of the existing acc, added to all four comps’ theme classes.

B · Prev / next item (comparator)

Order. The Library list as currently filtered, captured when the comparator opens. Items outside a component set form one group “Library” in Library (alphabetical) order; unreadable runs are excluded. Never crosses group boundaries; arrows disable at the ends. Position label “n / total”, 1-based. Demo root: 11 items, current = “Onboarding — Document step” = 5 / 11; prev Login, next Onboarding — Review step; chips All / Critical 4 / Major 3 / Minor 0 / Clean 4. A component set groups its rows by tone · size with uppercase section headers (“PRIMARY · MD”); the Library group is flat.

Switching. Swap only the artboards and findings. Keep zoom, pan, layer (Findings/Comments/All/Clean), variant (Off/Wipe/Onion/Blink/Diff), Split/Full, viewport, align-lock. Update URL and lastVisited. 1.6 s centre-top toast: arrow icon · item name · n / total · “zoom & layers kept” (transient, not drawn in comps).

Keyboard (desktop). ← → and K J prev/next; / focuses list search; ↑ ↓ ⏎ in the list; Esc closes. Ignored while focus is in an input.

Desktop header. Switcher replaces the static pair title: [‹] [Library / name n / total ⌄] [›], 32 px tall, bg2, 1 px line, radius 9; arrows 26×26, disabled = line colour, no pointer. Left header group is content-sized (flex 0 0 auto); the theme group on the right is the flexible spacer, so the Split/Full, variant and layer segments follow the switcher. Hover an arrow ≥150 ms → preview card (thumbnail, “Next · →”, name, severity). Click the name → 340 px popover under it, same pattern as the Viewport menu: search (autofocus, “/” hint, count), single-select severity chips, rows = dot · mono name · severity · check on current (current tinted vis), footer “↑ ↓ move · ⏎ open” + “n more below” when overflowing, scrim over the canvas closes it.

Mobile — no new panel. (1) Resting: mono counter “5/11” (11 px, txt2, padding 0 5 0 4) beside the brand square; 2 px hairline under the header, bg3 track, acc fill at n/total (0.25 s). Fit decision: header gap 7→4, padding 8→6, and the header variant segment’s button padding 9→7 px — Diff stays; the floating Findings pill and align pill are unchanged. (2) Tap brand/counter → header morphs: [✕] [‹ 44×36] [“Library · n / total” over the name, centred, ellipsised] [› 44×36] [list]; bottom border turns acc; auto-closes 4 s after the last interaction or on canvas tap; ✕ closes now. (3) List icon → bottom sheet at 62 % over a 35 % black scrim: handle, “Library · 11 items · Library order”, 36 px search, horizontally scrolling chips, 44 px rows (dot · thumb · mono name · severity · check), current row scrolled into view; tap a row = switch + sheet closes, header stays in switcher mode; drag handle up = full height; swipe down / scrim = dismiss. (4) Two-finger horizontal swipe on the canvas: artboard follows, peek card past 40 px (NEXT/PREV, thumb, name, severity, “release to open”), switch past ~80 px, else spring back; rubber-band only at group ends. Transient, not drawn.

Hover preview setting. showHoverPreview is a stored preference (default on) with no UI in the desktop comparator; it exists so the implementation can disable the card for users who find it noisy. Exposed in the comp as a Tweaks prop only.
