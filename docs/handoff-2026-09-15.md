## Key facts / decisions

- **Baseline before thresholds.** Plan steps 3–5 all make the matcher refuse more pairs, and refusal
  converts into missing + extra. A report where everything is missing and extra has not become more
  precise, it has failed differently. Step 2's corpus table is what tells them apart; a large
  matched-count drop on any pair is a REGRESSION.
- **Instrument before change.** Step 1 exists first because a raw finding count cannot evaluate a
  matcher change — the veto widening produced −10/+8 and told us almost nothing.
- **The pixel channel is no longer the only confidence-gated one** (it was, which is how 51 findings
  in a focus region were taken as trustworthy when their pairs were not). Step 1 closed that hole
  for `color` / `typography` / `border` / `border-radius` / `size` — by FLAGGING, never suppressing,
  because a suppressed finding cannot be told from "no difference here", which is the same bug with
  its sign flipped. `position` and `spacing` are still ungated and carry `via`/γ instead.
- **Confidence is evidence about a PAIRING only where the pairing came from geometry.** A
  `via: "text"` pair carries the same string on both sides and the transform played no part in
  forming it, so it is exempt from the gate at any confidence. This is the one place step 1
  deliberately sharpened the plan's wording; step 5 generalises it.
- The witness pair's numbers: 80 design leaves / 106 impl leaves, **42 matched**, alignment
  `(-10.5, 0.0)px`, **confidence 0.07 (x 0.50 / y 0.07)**, **225 findings** (35 critical / 127 major
  / 63 minor), of which 34 are flagged `unverified`. The pair's own thread-date mis-pairing is
  γ98.7 — the "70.7 px" quoted elsewhere is its position OFFSET, not its γ.
- `messages-accountant-desktop` captures a **thread deep link** because comp frame 1c opens thread
  t2 (`messages.dc.html` state `sel: { od: 0, ad: 1 }`); a bare route opens t1 and the whole
  conversation reports twice over as missing + extra.

## Env gotchas

- **`svc` needs `XDG_RUNTIME_DIR`** in non-interactive shells. Fixed in `/root/svc` `73e5d32`; if you
  are on a box without that commit, `export XDG_RUNTIME_DIR=/run/user/$(id -u)` before any `svc`
  call, or it dies with "Failed to connect to bus: No medium found" and looks like systemd is broken.
- **The devbox shells get a snapshot env**, so `~/.bashrc` edits do not reach the current session.
- **refdiff has NO formatter of its own, but the editing hook in a uctoinak2-rooted session does.**
  Every Write/Edit runs uctoinak2's `oxlint --fix` + `oxfmt` on the file, which strips semicolons
  from the 36 source files that still have them — so a three-line change to one of those arrives as
  a few hundred lines of diff. Commit the reformat separately FIRST (see `73cc4a1`), then the real
  change on top; otherwise the change is unreviewable. To produce the formatting-only commit, back
  the file up, `git checkout --` it, run the two commands by hand from `/root/uctoinak2`, commit,
  then restore.
- **`pnpm x` becomes `node x`** — a killed wrapper leaves the real worker alive. Verify with
  `ps -eo pid,etimes,args` before starting anything on the same port.
- **Never `git checkout --` a file with someone else's uncommitted work in it.** Done once this
  session, on `uctoinak2`'s accountant Messages page; restored from a full read earlier in the same
  context, which is luck, not a method.
- `/root/refdiff` and `/root/svc` are clean git repos. **No commits without Mato asking**; nothing is
  pushed. (Phase 1's two commits were asked for explicitly.)
- Three diagnoses were wrong before the real one (fixture data; a `cacheComponents`/Suspense theory;
  "same text ⇒ trustworthy pair"). Each survived a plausible argument and died on a measurement.
- **A number in a handoff is not a measurement.** Phase 1 started from "expect 448 core, 223
  findings" and both were wrong — 445 and 225 — because the previous session recorded run 13's
  numbers, which still had the widening step 0 removes. The plan's own "225 → 223" line said so.
  Re-measure the baseline before believing it, including when it is written down here.
