## Key facts / decisions

- **Zoom on select (`view-math.ts`, decided 2026-09-03).** Element + 70px context each side, a 60px
  floor on the element (that, not the 2.2× ceiling, is what stops a 0×0 anchor magnifying absurdly),
  cap 2.2×, zoom OUT when bigger than the pane. The pane INSETS bound the zoom as well as the
  centring — a deliberate divergence from the comps, which size from the full height and ignore
  their own bottom sheet; it also measured better (mobile ghost 93 → 89 versus 95 → 99 for a
  faithful copy). Result: desktop ghost 150 → 115, both zoom pills at 146%.
- **The pairing veto (`structural/match.ts`).** A candidate is refused when the two texts share no
  tokens, the distance is ≥ 20, AND each text occurs somewhere on the other side — positive evidence
  that both elements had a same-text partner available. Refused as a CANDIDATE (the assignment can
  still find the right partners), each pass using its own distance (γ in pass 2, position-only
  `slotGamma` in pass 3). Conservative on purpose; falsified per row against the corpus in
  `match.test.ts`.
- **A `pixel-region`'s identity is its `changeKind` + box**, never the measured ratio.
- **`delta.repaired`** names a regression whose element also had property findings resolved in the
  same run (a lost partner). A diagnosis, never a reclassification — a genuine vanish looks the same.
- **SVG extraction (`adapters/extract.ts`).** Atomic while every shape is icon-sized (≤64px) or
  there are more than 24; otherwise walked, children as `role: "shape"`, decided by the SHAPES not
  the svg's own box (a mark layer is a 1×1 px svg with `overflow:visible`). Paint maps to the HTML
  names exactly as the Figma adapter maps `fills`/`strokes`/`strokeDashes`; a paint SERVER goes to
  `backgroundImage`, captured and uncompared. `roles: ["shape"]` switches the channel off per pair.
- **A CSS class is a namespace.** The footprint is `.gfoot` because `.ghost` is the diff lab's
  superimposed design IMAGE at `opacity:0` — that collision made it paint nothing, invisibly.
- Source-of-truth pointers: `refdiff.bindings.md` (paths, ports, baseline, traps — READ IT FIRST),
  `skills/refdiff/SKILL.md` (the loop), `docs/architecture.md` → Open decisions,
  `docs/handoff-2026-09-02.md` (sessions 17–19 long form), `docs/lessons-inbox.md`.
