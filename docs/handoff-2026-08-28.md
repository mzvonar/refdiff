## Key facts / decisions

- **Everything durable lives in this repo** (docs/, skills/) — no Claude
  memory files; a fresh session recovers from the repo alone.
  `docs/architecture.md` "Open decisions" is the decision log,
  `docs/research.md` the evidence base.
- **The model is never the comparator**; the pass gate is deterministic;
  suppression stays visible under `suppressed`; a degraded capture is a
  typed `CaptureError`; one bad pair never kills a run (CLAUDE.md).
- **The skill ships with the code** (CLAUDE.md hard rule): any behaviour
  change updates `skills/refdiff/SKILL.md` in the same change; the skill
  stays repo-agnostic, repo specifics go in `refdiff.bindings.md`.
- **Measure, never eyeball**: every claim is a number from `findings.json`
  (`expected`/`actual` first, crops second); read `alignment` before any
  finding — and read the TRANSFORM, not only `confidence` (phase 5).
- `accepted.ts` REFUSES `position` / `spacing` rules (an offset lapses on
  every recapture) and textless rules without a handle — the reason items
  14 and 15 exist rather than a broader `accepted`.
- FP mandatory: pure stages beside thin adapters, typed `Ok | Err`; every
  pure module has a `*.test.ts`; a bug-fix test must fail without the fix.
- One world space = impl CSS px (the aligned frame) for every box; only the
  PNGs need per-side transforms.

## Env gotchas

- The CLIs run from `dist`: no `pnpm dev` / `pnpm build`, no effect. The
  running annotator never re-reads dist: `svc restart annotator`, then
  `curl <app-url>/ | grep <new-rule>` before an "after" measure.
- The Bash sandbox blocks outbound network and kills backgrounded servers —
  captures, comp hydration (unpkg + Google Fonts) and `--serve` need it off.
- `out/` is gitignored wholesale; the served root is `fixtures/demo-root/`,
  results go to `out/refdiff/`. Never serve the results root.
- The measured annotator is served `--read-only` (`services.toml`, item 16):
  PUTs are refused with 405. A writable serve of the fixture WRITES into it
  (`annotations.json` / `triage.json` / `focus.json`) — `git checkout
  fixtures/` or regenerate before a measure if you ran one.
- Port 7378 may be another worktree's annotator (`svc ports`).
- Global pre-push hook blocks pushes to main (`ALLOW_PUSH_TO_PROTECTED=1`);
  never push or commit unasked. Commit style: conventional type, no scope
  ticket, body at column 0, blank line before the `Co-Authored-By` footer.
- A raw U+2028 in a regex literal breaks tsc; no backtick anywhere inside
  `render.ts`'s CLIENT template (comments included).
