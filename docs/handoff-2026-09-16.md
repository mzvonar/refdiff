  −0.44 vs −0.71 for match rate), and its 0.35 threshold separates nothing: median junk-pairing rate
  **0.310 just below it, 0.313 just above**. The `joint-or-share` candidate reaches the right verdict
  for the wrong reason.
- **`MIN_AXIS_CONFIDENCE` currently excludes NOTHING that `MIN_MATCH_RATE` did not** — on this corpus
  `rate >= 0.70` alone gives the same 28/24 partition. Kept because the nearest pair sits EXACTLY on
  0.50 (`client-pending-accountant-mobile`) and it is live below the rate floor (13 of 24 clear it).
  **Until a pair fires it, "no single number detects the phase" is a claim this corpus does not
  demonstrate.**
- **Reading the comp is REQUIRED in `reconcile`, and the skill's blanket ban was over-scoped.**
  Mato's evidence: the naive phase (read the `.dc.html` / Figma + screenshots, then implement)
  produced **good general structure and bad details** — the exact complement of refdiff, which
  mis-pairs across divergent structure and is excellent on details. Two instruments with opposite
  failure profiles get aimed at the halves each is good at. What survives is narrower and still
  binding: **reading forms a hypothesis; the measurement adjudicates it.** The failure was never
  opening the file, it was calling the answer settled. Scoped in the frontmatter and §0.
- **The structure map is a CHECKLIST against reading, not a replacement for it.** Reading gives
  semantics and misses things silently; the map gives completeness. Its justification is unmeasured
  — hence the cheap test in item 2.
- **The witness `messages-accountant-desktop`:** 80 design / 106 impl leaves, 42 matched, alignment
  `(-10.5, 0.0)px` confidence 0.07 (x 0.50 / y 0.07), 225 findings, `phase: reconcile`, rate 0.53.
  Its six findings about `Včera` ↔ `Otázky · 1` (γ 98.7) are the canonical mis-pairing.
- **A phase must NEVER be a gate.** `today-owner-desktop` scores confidence 0.50 — over any sane
  floor — at match rate **0.31**, the worst in the corpus. Pinned by the `phase.test.ts` ratchet;
  the site it guards is `structural/checks.ts`, which already takes `alignmentConfidence`.
- **`identityKey` must keep ignoring provenance and phase.** Built from type + role +
  expected/actual + text, deliberately without geometry, so a human triage decision survives a
  recapture.
- **The gate FLAGS, it does not suppress** — a suppressed finding cannot be told from "no difference
  here". House rule in `CLAUDE.md`: suppression is visible or it does not happen.
- **A new file in `skills/refdiff/` ships automatically** (glob + `NOT_VENDORED`). Do not
  hand-maintain a list; the four self-test rows 9a–9d exist because the old list had already
  drifted and the manual check written to catch it matched a filename in a COMMENT.

## Env gotchas

- **The capture clock is FROZEN at `2026-09-15T12:00:00Z`** (`FROZEN_CLOCK`, `adapters/browser.ts`),
  chosen because that is the day the committed baseline was measured, so the baseline stays
  reproducible. Changing it re-dates every pair at once — a re-baseline, never a tweak. Opt out with
  `null`, **not `undefined`**: an explicitly-passed `undefined` re-triggers the default parameter.
- **A corpus can MEASURE ITSELF.** The `refdiff` corpus's impl is the annotator serving
  `fixtures/demo-root`, whose Library page renders the AGE of the runs it holds. Before the freeze,
  midnight took `refdiff-library-groups-desktop` from `matched` 197 → 196 / 560 → 561 findings with
  nothing edited — the exact signature step 2 calls a REGRESSION, manufactured by the calendar. Any
  baseline measured BEFORE `92b1f0a` is only comparable to a run from its own day.
- **A 307 is not proof the server is up.** An OOM-killed Next dev server leaves a poisoned Turbopack
  dist dir where every page and API route 500s while middleware redirects still answer 307 — so the
  handoff's old readiness probe passed on a server that then failed all 31 pairs with
  `auth-failed`. Probe `POST /api/test/session` (404 = compiled and ran); `rm -rf .next-design` and
  restart.
- **This box cannot run two dev servers and a capture browser.** 7 GB; a warm Next dev server holds
  ~3.4 GB. `free -m` and `dmesg -T | grep -i oom` BEFORE theorising; measure corpora in separate
  passes.
- **The CLIs run from `dist`, and every SERVER must be newer than the dist it runs.** A stale dist
  reports `+0/−0`, indistinguishable from a change that did nothing; a stale annotator serves a
  shell the source no longer describes. `svc restart annotator` before measuring.
- **A child process's errors are on STDERR** — a stdout-only capture reports a clean run.
- **A capture failure is evidence about the ENVIRONMENT, not a diagnosis.** Four pairs once had four
  plausible per-pair stories; one browser visit killed all four at once.
- **`pnpm storybook` hardcodes `-p 6006`**, so `svc`'s `$PORT` is ignored and `svc status` reports
  6007 where nothing listens. Probe 6006.
- **`svc down <name>` from a worktree that does not declare that unit can stop a DIFFERENT one.**
  Run it from the checkout that owns the unit, and check `svc status` after, not only before.
- **`svc restart` has the same shape, and it bit this session: two units are called `annotator`.**
  Run from a uctoinak2 checkout it restarted `svc-annotator@uctoinak2-5d19` on :7378 and printed
  `annotator: started`, while the refdiff unit on :7379 — the process that must be newer than
  `dist` — stayed as it was. The Bash tool resets cwd between calls, so **`cd /root/refdiff && svc
  restart annotator` in ONE command**, then confirm the PID moved in `svc status`. A wrong-unit
  restart is indistinguishable from a right one in its own output.
- **`svc` needs `XDG_RUNTIME_DIR`** in non-interactive shells, or it dies with "Failed to connect to
  bus" and looks like systemd is broken.
- **`pnpm x` becomes `node x`** — a killed wrapper leaves the real worker alive. Verify with
  `ps -eo pid,etimes,args` before starting anything on the same port.
- **refdiff has NO formatter, but a uctoinak2-rooted session's `PostToolUse` hook runs
  `oxlint --fix` + `oxfmt --write` on every file written.** The matcher's files are already in the
  target style so recent diffs stayed small; if you touch one of the ~36 files still carrying
  semicolons, **commit the reformat separately FIRST** (see `73cc4a1`, `29c43ee`).
- **Source/test files are created with Write/Edit only** — a `PreToolUse` guard blocks heredocs,
  `>`, `sed -i` and friends, because a shell-side write bypasses the formatting hooks.
- **A number written in a handoff is not a measurement.** Re-measure baselines, and name the run a
  number came from.
- **Never `git checkout --` a file carrying uncommitted work.** The `messages-redesign` worktree is
  OURS — this workstream's own WIP from earlier sessions — so edit and commit there normally,
  staging specific paths. Destroying uncommitted work is no more acceptable for being our own.
- `/root/refdiff` and `/root/svc` are clean git repos. `CLAUDE.md`: **do not commit unless asked**;
  nothing is pushed.
