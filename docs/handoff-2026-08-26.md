## What's DONE (this session — the first vertical slice)

All six planned steps, in `packages/core/src/`:

1. **Pipeline types + Result** — `result.ts` (`Ok | Err` + combinators),
   `pipeline.ts` (`SourceConfig`, `RefDescriptor`, `Capture`, typed
   `CaptureError` variants, `Pair`/`NormalizedPair`/`AlignedPair`,
   `ElementMatch`, pure `pairRefs`/`normalize`).
2. **`.dc.html` adapter** — `adapters/dc-html.ts` (+ shared
   `adapters/browser.ts`: serveDir with containment, freeze CSS,
   capture-until-stable, font wait). Frame by id→screen-label, hydration
   timeout is a typed `hydration-failed`, empty frame is `blank-render`.
   `adapters/extract.ts`: leaf element tree (boxes + computed styles) in
   page context, shared by both adapters; skips script/style, sr-only
   ≤2×2 boxes; descends through zero-size portal wrappers.
3. **Storybook adapter** — `adapters/storybook.ts`. Overlay (portaled
   dialog) stories: mount predicate requires content beside
   `#storybook-root`, extraction is viewport-origin. Error overlay →
   `story-error`, empty render → `blank-render`. Pixels settle BEFORE
   extraction so tree and shot agree.
4. **Structural channel** — `structural/align.ts` (pure per-axis
   Theil–Sen fit over unique-text anchors → total design→impl transform
   in `Alignment`; axes that don't fit stay identity),
   `structural/match.ts` (pass 1: unique-text identity matches; pass 2:
   GVT γ greedy with 100px cutoff), `structural/checks.ts` (typed checks
   + severity per research §3, sorted/numbered findings).
5. **Agent packaging** — `package/package-for-model.ts`: findings.json,
   set-of-marks overlay (severity-colored numbered marks on impl),
   per-finding crop pairs (design crop via inverse alignment transform),
   `elements.json` with both trees.
6. **CLI `compare`** — flags for one dc-html/storybook pair, exit codes
   0 pass / 1 findings / 2 typed capture error. Proven on
   `doc-detail-owner-desktop` and `tx-picker-owner-desktop`.

### Learnings from the real corpus (drive the next steps)

- **Every `.dc.html` frame is an artboard**, not a component: label
  strip, demo-state chips, dark backdrop, designer-notes paragraph, and
  no addressable modal-only node. That's why the structural alignment
  stage exists NOW (pure, element-data-only — no NCC needed): it absorbs
  the offset/scale; the chrome itself still (correctly) reports as
  missing-elements.
- **Seed-data mismatch dominates findings**: comps show different demo
  data than the storybook stories (Alza vs Slovak Telekom, different
  transaction rows), so many missing/extra + text findings are true but
  uninteresting. This promotes **NL ignore-policies / dynamic-content
  handling** from "later" to the next work item.
- Overlay stories leave `#storybook-root` empty (portal to `<body>`) —
  already handled, but remember for the live-URL adapter.

## Key facts / decisions

- **The model is never the comparator** — deterministic findings gate
  everything. Full rationale + citations: `docs/research.md`.
- Decisions locked with Mato: one repo / two packages; public GitHub
  (mzvonar/visual-compare); core = CLI + library wrapped by a thin skill
  (MCP maybe later); both Figma and `.dc.html` ref sources supported
  (dc.html first — richest data); **FP paradigm mandatory**: pure
  composable stages, immutable data, typed `Ok | Err` results, effects
  only at adapter edges, every stage independently importable. Plain
  typed functions for now (no Effect library) — revisit if noisy.
- Reference implementations to port from (don't reinvent):
  `~/Development/uctoinak-bmad/tools/design-compare/` (renderer, capture,
  compose, skill with "measure don't eyeball" checklist) and
  `~/Development/inno-workspace/repos/population-registry/frontend/ds/tooling/visual/`
  (Figma REST layer `figma-api.mjs` with cooldown handling, annotator UI
  + state machine, `pngsample.mjs`/`pnggrid.mjs` zero-dep pixel readers).
- Blueprint: GVT (ICSE 2018) — leaf boxes, γ-distance matching, typed
  per-pair checks, scoped pixel diff; calibration constants 5px / 20% /
  85% come from that paper.

## Env gotchas

  `ALLOW_PUSH_TO_PROTECTED=1 git push …`. Mato pushes this repo himself —
  **never push unasked** (his global rule: also never commit unasked).
- Commit style: conventional commits, subject ≤50 chars, no ticket scope
  (personal repo), body bullets at column 0, footer
  `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- `pnpm install` warns about missing `dist/cli.js` bins — harmless until
  first `pnpm build`.
- `.dc.html` comps load React from unpkg and Google Fonts — design-side
  rendering needs network; treat offline/unstyled render as a typed
  capture error (the old harness screenshotted it "successfully").
- uctoinak-bmad expects `PLAYWRIGHT_BROWSERS_PATH=/mnt/data/playwright`
  in its own env — do NOT copy that into visual-compare; use default
  browser install (`pnpm exec playwright install chromium`).
