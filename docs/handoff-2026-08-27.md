## Key facts / decisions

- **Everything durable lives in this repo** (docs/, skills) — Mato wants no
  Claude memory files; a fresh session must recover from the repo alone.
  `docs/architecture.md` "Open decisions" is the decision log; `docs/research.md`
  the evidence base (read before changing any comparison decision).
- **The model is never the comparator** — deterministic, typed, measured
  findings gate everything; the model reads `expected/actual` first, crops
  second. Suppression stays visible under `suppressed`; aggregation loses no
  information (`members[]`); a degraded capture is a typed `CaptureError`,
  never a `Capture`; adapters always save the FULL images
  (`artifacts.designPng/implPng`) for the human split view.
- **FP mandatory**: pure composable stages, immutable data, typed `Ok | Err`
  (`result.ts`), effects only at adapter edges (`adapters/*`, `pixel/diff.ts`,
  `package-for-model.ts`, both `cli.ts`). Plain functions, no Effect library.
- **One world space** = impl CSS px (the aligned frame): every Finding box,
  `elements.json` (both trees), annotation shapes and anchors. Only the PNGs
  need per-side transforms (impl via DPR; design via DPR + `Alignment`,
  `geometry.ts` inverse / `view-math.ts` `worldToDesign`).
- Design scale policy: `.dc.html` → `auto` (impl width / design width);
  Figma → `1` (units ARE CSS px; a wider frame is layout, not scale).
- Alignment: Theil–Sen per axis over UNIQUE-text anchors (≥3); with fewer,
  a pure offset only when every design leaf is an anchor; confidence damped
  by `anchors/8`; pixel channel waits for ≥0.5.
- The unit of a design-system comparison is one variant COMPONENT ↔ one
  story cell, never the sheet — `design.variants` in a manifest expands a
  set into exactly those pairs (tagged cells robust, positional cells
  fragile; see S10).
- **Intended deviations are `accepted` with evidence, never fixed blind:**
  before changing a shared token because one comp says so, census the
  sibling comps (`grep -o '#hex' *.dc.html | wc -l`); doc-detail's
  `#1a1a1a` ink and ochre pill were both outliers (11/13 and 3/3 comps
  disagree) → `ignore.accepted` in the uctoinak manifest, reason = the
  numbers.
- **The regression guard is the tool's:** `resolved-ledger.json` per run
  dir; `delta.regressions` / `REGRESSION:` — the skill stops the plan on it.
- Blueprint: GVT (ICSE 2018) — leaf boxes, γ-distance matching, typed
  per-pair checks, scoped pixel diff; constants 5px / 20 % / 85 %.
- Reference implementations (ported from, don't reinvent):
  `~/Development/uctoinak-bmad/tools/design-compare/` (renderer, capture,
  skill checklist, `serve-live.sh`) and
  `~/Development/inno-workspace/repos/population-registry/frontend/ds/tooling/visual/`
  (`figma-api.mjs`, `frames.json`, annotator + `mark-implemented.mjs`).
- `@blazediff/*` evaluated and declined (architecture.md); its `regions[]`
  protocol and `interpret-native` signal set are the reference for plan §4.
